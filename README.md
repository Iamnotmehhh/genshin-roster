# 原神养成记录助手

一个给单个原神玩家用的本地角色 / 圣遗物 / 抽卡记录管理工具。**免安装，双击即用。**

> 非米哈游官方工具，与米哈游无关；仅供个人学习记录使用。

## 功能一览

- 📋 **角色养成记录** —— 角色表（年份分组/排序/搜索/筛选）、行内编辑、角色档案、定位标签
- ☁️ **UID 展柜同步** —— 输入 UID，从 Enka 展柜接口一键同步角色/武器/圣遗物/天赋/命座（无需任何登录凭证）
- 🎒 **圣遗物工具** —— 分配优化（多角色平衡 / 总收益双方案）、单角色最优搭配、词条计算器、圣遗物池
- 🔍 **圣遗物筛选** —— 五闸门判定（锁死 → 极品保护 → 稀缺槽 → 全流派评分 → 回收站）
  - 当前穿戴列（这件现在穿在谁身上）
  - 场景推荐（散件 / 2件套 / 4件套 三种假设下各自最适合给谁）
  - 得分明细（点击得分查看完整打分账单）、得分计算器（试算假想圣遗物）
  - 强化表（每种副词条强化一次的档位）
- 🎴 **抽卡记录** —— 从游戏缓存一键同步全部祈愿记录（增量合并），统计面板：各卡池五星数、平均几抽一金、当前保底进度；导出 CSV
- ☁️ **云端同步（百度网盘）** —— 全部数据（角色 / 圣遗物 / 抽卡记录）一键备份到自己网盘的专属目录，换电脑自动拉回

## 下载

到 [Releases](../../releases/latest) 页面下载最新版 `原神养成记录助手.exe`（免安装，双击即用）。

## 快速上手

1. 双击 exe（Windows 若弹"已保护你的电脑"警告：点"更多信息" → "仍要运行"）；
2. 点顶部「UID 同步」→ 输入 9 位 UID 同步展柜数据（需游戏内展柜公开）；
3. 切到「🎴 抽卡记录」→ 在装有原神的电脑上点「从游戏同步」拉取祈愿记录；
4. 圣遗物筛选页开始管理你的圣遗物；
5. 点「云备份」→ 在弹窗内填写 AppKey/SecretKey（只显示掩码，密钥保存在本机受系统保护的配置中）→ 数据备份到百度网盘（换电脑自动拉回）。

如果抽卡同步没有自动找到缓存目录，可在抽卡记录页面点击「设置游戏/缓存目录」，填写原神安装目录或 `webCaches` 目录后保存。关闭应用窗口后，后台助手会在确认页面已退出后自动结束。

详细说明见压缩包内的 `README-setup.txt`。

## 安全说明

- 不采集任何隐私数据；联网功能仅两项：**把你自己的数据备份到你自己授权的百度网盘目录**、读取 Enka 展柜公开数据；
- 本仓库不含任何密钥 / 凭证文件。

## 技术栈

单文件 HTML + CSS + JavaScript（前端）、Python 3.12 标准库（本地助手，零第三方依赖）、PyInstaller 打包。
